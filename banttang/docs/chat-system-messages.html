#케이스예정 문구상태event
–거래 30분 전거래 30분 전입니다 enum/타입에만 정의 · 삽입 코드 없음 (스케줄러 미연동)before_30min
–거래 10분 전거래 10분 전입니다 enum/타입에만 정의 · 삽입 코드 없음 (스케줄러 미연동)before_10min
※ before_30min / before_10min은 거래 임박 알림 용도로 enum에만 존재하며, 현재 채팅 메시지로 삽입하는 코드가 없어 방에는 나타나지 않습니다 (pg_cron/스케줄러 연동 시 활성화 가능).
※ system_event vs metadata.kind — event는 DB enum(진행상태 추적·legacy party_closed 포함), kind는 chat-timeline.tsx의 렌더링 분기용입니다. 모집 오픈/완료처럼 event만 쓰는 케이스와, 취소/띵동처럼 kind만 쓰는 케이스가 섞여 있습니다.
※ 노출 대상은 metadata.recipient로 제어합니다 — 미지정=전원, "host"=호스트+발신자 본인, "member"=멤버만(호스트 숨김).
※ 이 문서의 모든 문구는 2026-06-24 기준 소스 코드에서 직접 확인한 원문입니다.
