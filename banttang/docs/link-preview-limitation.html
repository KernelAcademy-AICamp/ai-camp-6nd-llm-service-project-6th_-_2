채팅 링크 썸네일(OG 프리뷰) — 동작 범위와 한계

반띵 · 채팅 기능 기술 메모 · 2026-06-24
한 줄 요약. 유튜브·뉴스·SNS 등 OG 태그를 정직하게 제공하고 봇을 막지 않는 사이트는 무료로 썸네일 카드가 뜬다. 쿠팡·네이버 스마트스토어·G마켓·11번가 같은 대형 커머스는 불가능하다. 이유는 (1) 봇 차단, (2) OG 미제공, 그리고 (3) 우리가 웹앱(브라우저/PWA)이라는 구조적 제약 때문이다.

1. 링크 썸네일은 어떻게 만들어지나

카카오톡처럼 URL만 넣어도 이미지·제목이 뜨는 건 웹페이지의 Open Graph(OG) 메타 태그 덕분이다. 사이트가 <head>에 og:title, og:image, og:description 같은 태그를 넣어두면, 그 페이지의 HTML을 받아 태그만 파싱해서 카드를 만든다.

우리 구현도 동일하다: 서버 라우트(/api/og)가 URL의 HTML을 받아 OG 태그를 추출 → 채팅 버블 아래 카드로 표시.

2. 실제 테스트 결과

사이트결과원인
유튜브 / 네이버 뉴스✅ 됨OG 태그 정상 제공, 봇 허용
당근마켓 · 배달의민족 · 마켓컬리 · 다나와 · 인스타그램✅ 됨OG 제공
네이버 스마트스토어❌ 불가봇 차단 (HTTP 429)
쿠팡 (상품 링크 포함)❌ 불가봇 차단 (HTTP 403)
G마켓 · 옥션❌ 불가봇 차단 (HTTP 403)
11번가❌ 불가OG 태그 없음 + JS 렌더링

정리하면 국내 대형 오픈마켓은 전부 불가, 그 외 일반 사이트는 대부분 가능.

3. 카카오톡은 왜 쿠팡·네이버도 되나

  • 카카오·슬랙·페이스북의 크롤러 IP 대역이 네이버/쿠팡 화이트리스트에 등록돼 있다. (역DNS로 "진짜 카카오 봇 맞는지" 검증까지 함)
  • 그래서 차단 없이 페이지를 받아오고, 네이버는 이 봇들에게 가격·할인·별점까지 풍부한 데이터를 내려준다.
  • 우리가 UA(User-Agent)를 kakaotalk-scrap으로 위장해도 막힌다 → 네이버는 UA가 아니라 IP로 차단하기 때문. (실제 테스트로 확인: 카카오·슬랙·페북·구글봇 UA 전부 429)

일반 서비스가 이 화이트리스트에 들어가는 것은 사실상 불가능하다.

4. "휴대폰 IP로 받아오면 되지 않나?" — 웹앱은 불가

어떤 블로그(Flutter 앱 사례)에서는 accept-encoding · accept-language 헤더만 넣어 쿠팡 OG를 받아왔다. 하지만 그건 네이티브 모바일 앱이라 가능했던 것이고, 우리 웹앱에선 재현되지 않는다. 핵심은 두 가지 조건이다.

조건 ① 주거용(휴대폰) IP

쿠팡·네이버는 데이터센터 IP는 차단하고 휴대폰·가정용 IP는 허용한다. 우리 서버(Vercel 등)는 데이터센터 IP라 403/429. 네이티브 앱의 요청은 폰에서 직접 나가므로 주거용 IP가 된다.

조건 ② CORS 없음

브라우저에서 다른 도메인(coupang.com)으로 fetch()하면, 요청은 가도 쿠팡이 허용 헤더(Access-Control-Allow-Origin)를 안 주기 때문에 브라우저가 응답 본문을 못 읽게 차단한다. no-cors로 보내면 응답이 "opaque"라서 역시 내용을 읽을 수 없다. 즉 OG 파싱 불가. 네이티브 앱의 HTTP는 브라우저가 아니라서 이 CORS 제약 자체가 없다.

방식주거용 IPCORS 없음가능?
브라우저 fetch (현재 웹/PWA)✅❌❌
서버 fetch (현재 /api/og)❌ 데이터센터 IP✅❌ (403/429)
네이티브 앱 (Flutter/RN/Capacitor)✅✅✅
왜 웹앱은 절대 안 되나: "주거용 IP"와 "CORS 없음" 두 조건을 동시에 만족해야 하는데, 브라우저는 두 번째(CORS)를 절대 풀어주지 않는다. 서버로 돌리면 첫 번째(IP)에서 막힌다. 그래서 웹/PWA 구조에선 구조적으로 불가능하다.

5. 결론 & 선택지

  • 현재 (무료, 권장): 차단 안 하는 사이트는 썸네일 카드, 차단/미지원 사이트(쿠팡·네이버스토어 등)는 깔끔하게 축약된 링크로 표시. 추가 비용·의존성 없음.
  • 유료 우회: microlink 등 외부 스크래핑 API (주거용 IP 로테이션 사용). 네이버 뚫림 확인됨. 단 무료 한도(하루 ~50회) 초과 시 유료(월 $24~), 외부 의존·지연·프라이버시(사용자 링크가 제3자로 전송) 이슈 있음.
  • 근본 해결: 앱을 네이티브로 패키징(Capacitor 등)하면 device HTTP로 폰 IP에서 직접 받아와 쿠팡·네이버도 가능. 단 "웹앱 → 네이티브 앱" 별도 작업 필요.
